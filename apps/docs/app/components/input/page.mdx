# Input

A text input with sizes, error states and adornments. Labels and help text come from `Field`.

    <Input placeholder="you@example.com" className="story-md" />
  </Field>
</Preview>

## Import

```tsx
import { Input } from '@mizunagara/react';
```

## With label and help text

Wrap the input in `Field`. Its `label` and `description` props render the label and help text, and it wires up `htmlFor` and `aria-describedby` for you.

```tsx
<Field label="Email" description="We won't share this.">
  <Input placeholder="you@example.com" />
</Field>
```

## Migrating from `label` and `helpText`

`Input` no longer accepts `label` or `helpText` (a breaking change in 0.x). Wrap the input in `Field` instead:

| Before                                    | After                                                       |
| ----------------------------------------- | ----------------------------------------------------------- |
| `<Input label="Email" />`                 | `<Field label="Email"><Input /></Field>`                    |
| `<Input helpText="Help" />`               | `<Field description="Help"><Input /></Field>`               |
| `<Input label="Email" helpText="Help" />` | `<Field label="Email" description="Help"><Input /></Field>` |

Move each `label` to `Field`'s `label` prop and each `helpText` to `Field`'s `description` prop, then search your code for `label=` and `helpText=` on `<Input>` tags to find the rest.

## Sizes

```tsx
<Input size="sm" placeholder="Small" />
<Input size="md" placeholder="Medium" />
<Input size="lg" placeholder="Large" />
```

## Props

| Prop       | Type                   | Default | Description                |
| ---------- | ---------------------- | ------- | -------------------------- |
| `size`     | `'sm' \| 'md' \| 'lg'` | `'md'`  | Input height               |
| `label`    | `string`               | —       | Auto-wraps in a form group |
| `error`    | `string \| boolean`    | —       | Error message or state     |
| `helpText` | `ReactNode`            | —       | Help text below            |
| `disabled` | `boolean`              | `false` | Disables the input         |

All native `<input>` attributes are also accepted.

## Guidelines

**Do:**

- Always provide a visible label or `aria-label`
- Show validation errors inline

**Don't:**

- Don't use placeholder text as a label substitute
