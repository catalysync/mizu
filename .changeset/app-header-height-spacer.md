`AppHeader` height can now be set with `--mizu-app-header-height` (default `3.5rem`). The new `spacer` prop (default `true`) lets you turn off the flexible gap between nav and actions. The unused `.mizu-app-header__search` rule is removed; it was not referenced by any component.
