Tabs gain a `variant` prop (`underline` by default, or `segmented`), a `size` prop (`sm`, `md`, `lg`) and vertical orientation. Vertical tabs move with the up and down arrow keys. Disabled tabs are dimmed, and keyboard focus draws the shared focus ring. The active indicator colour can be set with `--mizu-tabs-indicator-color`. This is additive; existing tabs render as before, apart from the new focus ring.
