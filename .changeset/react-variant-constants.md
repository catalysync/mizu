Exports the variant maps for Button, Badge, Alert, Tag and Input as `MIZU_BUTTON_VARIANTS`, `MIZU_BADGE_VARIANTS`, `MIZU_ALERT_VARIANTS`, `MIZU_TAG_VARIANTS` and `MIZU_INPUT_VARIANTS`, so tooling can read the allowed values. Rendered classes are unchanged; this is additive and not a breaking change.
