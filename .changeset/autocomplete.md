add Autocomplete, a free-text input that filters suggestions as the user types. Enter selects the highlighted suggestion and a click selects any suggestion; both report through `onOptionSelect`, and the typed text is kept in `value` / `onValueChange`. It is available from the root export and from `@mizunagara/react/autocomplete`.
